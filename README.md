# Pit Career: Series 3

A trading-floor revision game for the NFA Series 3 (National Commodity Futures) exam.

**Play:** https://smelliott121.github.io/series3-pit-career/

- 10 desks (one per chapter), career ranks, margin calls and liquidation
- The Real Exam: 120-question mock, 2h30, 70% needed in both parts
- Daily drill, Damage Control (spaced review), Open Outcry, Order Desk, Contract Match, Cheat Sheet
- Progress is saved in your browser (per device)

## Editing questions
Questions live in `src/questions/`. After editing, run `python3 src/build.py` to rebuild `index.html`.
